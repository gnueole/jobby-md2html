About jobby MD Editor

jobby MD Editor

Version 1.4.0

A premium Markdown resume editor designed to blend elegant aesthetics with flawless ATS (Applicant Tracking System) compliance.

Inspired by rozita-hasani/markdown-resume.

📝 Specific Resume Directives (Guide)

  • Accent Color: Use :accent[your text] to color important elements (e.g., :accent[Immediately available]).
  • Muted Text (gray): Use :muted[your text] to visually de‑emphasize secondary information while keeping it indexable by ATS (e.g., :muted[Driver's license B · Own vehicle]).
  • Contact Bar: Automatically formats emails or links. Force a centered block with [CONTACT : email | phone | linkedin].
  • Two-Column Layout: If 2-column mode is enabled, ### (H3) headings go to the left Sidebar, and ## (H2) headings go to the right Main column.
